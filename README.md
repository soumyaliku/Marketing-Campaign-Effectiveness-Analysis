# Marketing Campaign Effectiveness Analysis

## 📌 Project Overview

An end-to-end Data Analytics project focused on analyzing marketing campaign effectiveness using Python and Power BI.

The project transforms customer and marketing data into meaningful insights around campaign performance, leads, conversions, spending, purchases, ROI, and CPA.

## 🎯 Objectives

- Analyze marketing campaign performance
- Evaluate ROI and CPA
- Understand lead generation and conversion patterns
- Compare purchasing channels
- Analyze customer spending behavior
- Generate data-driven marketing insights

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Power BI
- Data Cleaning & Preprocessing
- Exploratory Data Analysis
- Feature Engineering
- Data Visualization

## 🔄 Data Preparation

The dataset was processed through several steps:

- Handled missing values
- Converted date fields
- Transformed categorical variables
- Removed duplicate records
- Created derived features
- Detected and handled outliers using the IQR method
- Applied Min-Max Scaling to selected expenditure features
- Saved the processed dataset for further analysis

## 📊 Power BI Dashboard

The processed data was used to create an interactive Power BI dashboard.

### Key KPIs

- ROI
- CPA
- Total Conversions
- Total Leads
- Total Spending
- Total Purchases

### Analysis Included

- ROI trends over time
- Lead generation analysis
- Purchase channel comparison
- Spending distribution
- Campaign performance
- Customer and marketing behavior

## 💡 Key Insights

The analysis highlighted differences in performance across marketing and purchasing channels.

Store purchases represented the highest-volume purchase channel among the analyzed channels, followed by web and catalogue purchases.

The project also demonstrates how ROI, CPA, leads, and conversions can be analyzed together to evaluate campaign effectiveness.

## 📈 Business Value

This analysis can help marketing teams:

- Compare campaign and channel performance
- Identify stronger-performing sources
- Evaluate marketing efficiency
- Understand customer purchasing behavior
- Support data-driven resource allocation
- Monitor campaign performance through interactive dashboards
